# ANKARA Perfumeria

Landing page de ANKARA Perfumeria hecha en Angular.

## Desarrollo

```bash
npm install
npm start
```

Abre http://localhost:4200.

## Editar productos

Los perfumes, precios y el numero de WhatsApp estan en `src/app/data/perfumes.ts`.
Para usar fotos reales, ponlas en `public/perfumes/` y agrega `imagen: 'perfumes/foto.jpg'` al perfume.
